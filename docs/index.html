Action-Class Gate Lab

Run an action through the reversibility-graded gate and watch what it decides, in the browser. Nothing is sent anywhere.

This is the reference, not a product. It implements the same model as reversibility/model.py, chain.py and observation.py in the conformance repository, so it grades identically to the suite. It is not a candidate for the results index: it is the thing rows in that index are compared against. No real systems, credentials or data touch it, and there is no server.
